# Privacy Policy — L'Historien du Soir uploader

This tool is used only by the owner of the YouTube channel "L'Historien du Soir" to upload and schedule the channel's own videos through the YouTube Data API.

- It accesses only the owner's own YouTube channel, with the owner's consent.
- It uploads videos, sets thumbnails, adds videos to playlists and lists the channel's own uploads.
- It does not collect, store, sell or share any personal data of other users.
- OAuth credentials are kept as encrypted GitHub Actions secrets and are used only to upload the channel's videos.
- Access can be revoked at any time at https://myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: through the YouTube channel "L'Historien du Soir".
